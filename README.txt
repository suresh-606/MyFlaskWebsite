FLASK HELLO WEBSITE

1. Open this folder in VS Code or a terminal.
2. Create/activate a virtual environment (recommended):
   Windows:
       python -m venv venv
       venv\Scripts\activate

   macOS/Linux:
       python3 -m venv venv
       source venv/bin/activate

3. Install Flask:
       pip install -r requirements.txt

4. Run the website:
       python app.py

5. Open in your browser:
       http://127.0.0.1:5000/

The website displays a modern "Hello, this is my website!" page.
